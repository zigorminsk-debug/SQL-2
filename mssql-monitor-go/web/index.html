Подключение к SQL Server

Программа только читает системные представления (SELECT к DMV). Для полного отчёта требуется право VIEW SERVER STATE.

Демонстрация

Демо-режим подключает «виртуальный» проблемный SQL Server (без обращения к сети) — удобно, чтобы посмотреть отчёт и интерфейс.

Суточный мониторинг

Программа опрашивает сервер по интервалу и накапливает показатели: CPU, запросы/с, память, ожидания, блокировки, долгие запросы. Данные хранятся локально (JSONL) и попадают в отчёт.

О программе

MS SQL Monitor — контроль ресурсов, скорости обработки и настроек Microsoft SQL Server с рекомендациями по устранению проблем.

  • Только чтение: SELECT к системным представлениям (DMV), ничего не изменяет.
  • Суточный мониторинг с графиками загрузки и разбором причин замедлений.
  • Подробный HTML-отчёт с рекомендациями и готовыми T-SQL командами (применяются вручную).
  • Требуемые права: VIEW SERVER STATE; чтение msdb — для бэкапов и заданий.

Реализация на Go, один исполняемый файл, без установки. Веб-интерфейс работает на локальном адресе этого компьютера.
