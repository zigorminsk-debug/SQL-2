# Передача проекта следующему агенту

Этот файл — постоянный журнал правил сборки и контекста для продолжения работы.
Обновляйте раздел «Последние изменения» при изменении процесса сборки.

## Что является актуальным приложением

В репозитории две реализации одного инструмента:

- `mssql-monitor-go/` — основная автономная Go-версия (GUI и CLI);
- `mssql-monitor/` — исходная Python-версия (GUI и CLI).

Обе реализации намеренно собираются, чтобы изменения одной версии не сломали
поставку другой.

## Автоматическая сборка

- Единственный активный GitHub Actions workflow: `.github/workflows/build-windows.yml`.
- Он автоматически стартует на **каждый push в любую ветку** и на pull request.
- Ручной повторный запуск доступен через `workflow_dispatch`.
- Два независимых job собирают Go- и Python-версии на `windows-latest`.
- Результаты загружаются как отдельные artifacts с SHA коммита в имени.
- При новом push незавершённая сборка старого коммита той же ветки отменяется.

Важно: GitHub распознаёт workflows только в корневом `.github/workflows`.
Старый файл `mssql-monitor/.github/workflows/build-windows.yml` был перенесён,
поскольку из вложенной директории он никогда не мог запускаться автоматически.

## Локальные проверки перед push

```sh
(cd mssql-monitor-go && go test ./... && go vet ./... && go build ./...)
(cd mssql-monitor && python -m compileall -q .)
```

Полная Windows-сборка выполняется CI. На Windows её также можно запустить через
`build.bat` в соответствующей папке.

## Последние изменения (2026-10-02)

1. Workflow перенесён в правильную корневую директорию.
2. Автотриггер расширен с `main/master` до любой рабочей ветки и pull request.
3. Добавлена сборка обеих реализаций, проверки `go test`, `go vet` и `compileall`.
4. Артефакты привязаны к SHA, а параллельные устаревшие сборки отменяются.
5. Python-исходники локально успешно прошли `python3 -m compileall -q .`.
6. Go локально не проверялся: в текущем контейнере команда `go` отсутствует;
   точная проверка и Windows-сборка выполняются новым CI с версией из `go.mod`.
