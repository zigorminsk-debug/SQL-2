ГосПорталы РБ

Все государственные порталы Беларуси + настройки для входа — в одном окне

Диагностика рабочего места

Проверка типовых «настроек для входа» на госпорталы: криптопровайдер, сертификаты, браузер. Никакие данные с компьютера никуда не отправляются — всё выполняется локально.

Что нужно для входа по ЭЦП

Юрлица и ИП работают на госпорталах с электронной цифровой подписью. Минимальный набор:

1. Криптопровайдер AVEST CSP

Национальное СКЗИ: без него не работают МНС, ФСЗН, Минфин, Белгосстрах, Белстат по ЭЦП. 30 дней — бесплатный ознакомительный период.

avest.by → скачать

2. Сертификат ключа ЭЦП

Выдаётся удостоверяющим центром (РУЦ ОСТ, НУЦ, ГосСУОК — для бюджетников). Ключевой носитель — токен/флешка AVEST.

nca.by — Нац. удостоверяющий центр

3. Корневые сертификаты НУЦ / ГосСУОК

Устанавливаются в «Доверенные корневые» Windows, иначе порталы выдают ошибку «сертификат не доверенный».

nca.by · gosuok.gov.by

4. AvTuneProxy (вход «без ЭЦП»)

Нужен только для Корпоративного портала ФСЗН при входе по логину МСИ вместо ЭЦП.

avtunproxy.by → скачать для Windows

5. Браузер с режимом IE

МНС (физическая ЭЦП) и «Электронный респондент» Белстата работают в Internet Explorer 11 или Edge в режиме IE. МЭЦП и логин/пароль — в любых браузерах.

инструкция по включению режима IE ↓

6. Токен с драйвером

Для аппаратных носителей AVEST ключ виден в «Диспетчере сертификатов» (AvCertMgr) после установки AVEST CSP.

документация Avest →

Включение режима IE в Microsoft Edge

  1. Откройте Edge → «…» → Параметры → Браузер по умолчанию.
  2. «Разрешить сайтам перезагрузку в режиме Internet Explorer» → Разрешить, перезапустите Edge.
  3. «Страницы в режиме Internet Explorer» → Добавить страницу и введите адрес портала (например, http://e-respondent.belstat.gov.by/belstat/ для Белстата).
  4. Откройте портал из панели — страница загрузится в режиме IE (значок ℹ «Internet Explorer» рядом с адресом).

Идентификация без ЭЦП (МСИ, ЕСА, логин/пароль)

МСИ — Межбанковская система идентификации

Подтверждение личности онлайн: доступ в ЛК МНС (физлица), ФСЗН «без ЭЦП», банки. Регистрация — на сайте ЕРИП, в банке или мобильном приложении.

регистрация/вход в МСИ →

ЕСА — Единая служба аутентификации

Единая учётная запись для portal.gov.by, «Обращений» и других госуслуг. Регистрация — онлайн на портале услуг, в сервисном центре ОАИП или через МСИ.

auth.gia.gov.by →

Логин/пароль ЛК МНС (физлица)

Учётная запись выдаётся бесплатно в любой налоговой (по паспорту) либо удалённо — через МСИ или оператора МТС/А1/life.

lkfl.portal.nalog.gov.by →

Как работать с панелью

  1. Найдите нужный портал поиском или по категориям. Зелёная точка — портал отвечает, серая — проверка... красная — недоступен (возможно, регламентные работы).
  2. Нажмите «Войти» — откроется официальная страница входа в новой вкладке. Логин и пароль вводите только там.
  3. Звёздочкой ★ добавляйте частые порталы в избранное (хранится локально в этом браузере).
  4. Вкладка «Настройки входа» — проверка крипто-окружения и список необходимых программ/сертификатов.
  5. Быстрый переход к поиску — клавиша /.

Безопасность

🛡 Приложение работает полностью локально, не запрашивает и не хранит логины/пароли/ЭЦП, ничего не отправляет в интернет (кроме проверки доступности самих порталов). Аутентификация выполняется только на официальных доменах *.gov.by и официальных сервисах. Всегда проверяйте адрес сайта и сертификат перед вводом данных.

О программе

Настольная панель идейно похожая на BELPORTAL (belportal.by): одно окно вместо десятков ярлыков. Однофайловый .exe, установка не требуется, ничего лишнего. Список порталов и справочные подсказки собраны из официальных источников; перед отчётным периодом сверяйте адреса с сайтами ведомств.
