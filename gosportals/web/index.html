Диагностика рабочего места

Проверка «настроек для входа». Запускается автоматически при старте; здесь можно повторить. Всё выполняется локально.

Что нужно для входа по ЭЦП

1. Криптопровайдер AVEST CSP

Национальное СКЗИ: без него не работают МНС, ФСЗН, Минфин, Белгосстрах, Белстат по ЭЦП.

avest.by → скачать/обновить

2. Сертификат ключа ЭЦП

Выдаётся удостоверяющим центром (РУЦ ОСТ, НУЦ, ГосСУОК). Носитель — токен/флешка AVEST.

nca.by →

3. Корневые сертификаты НУЦ / ГосСУОК

Ставятся в «Доверенные корневые» Windows. Следите за сроками — приложение подскажет об истечении.

nca.by · gosuok.gov.by

4. AvTuneProxy (вход «без ЭЦП»)

Нужен только для ФСЗН при входе по логину МСИ вместо ЭЦП.

avtunproxy.by → скачать

5. Браузер с режимом IE

МНС (физическая ЭЦП) и «Электронный респондент» Белстата работают в IE 11 / Edge в режиме IE. Если портал запрещает встроенные вкладки — он откроется отдельным окном автоматически.

6. Токен с драйвером

Носитель виден в «Диспетчере сертификатов» (AvCertMgr) после установки AVEST CSP.

документация →

Включение режима IE в Microsoft Edge

  1. Edge → «…» → Параметры → Браузер по умолчанию.
  2. «Разрешить сайтам перезагрузку в режиме Internet Explorer» → Разрешить, перезапустите Edge.
  3. «Страницы в режиме IE» → Добавить страницу — адрес портала.
  4. Открывайте портал из панели — загрузится в режиме IE.

Как работать

  1. При запуске приложение само проверяет сертификаты и зависимые программы — результат в полосе сверху списка порталов.
  2. Клик по плитке открывает портал в новой вкладке внутри этого окна; переключение — по полосе вкладок (⌂ Главная всегда слева). Длинные названия сокращаются аббревиатурой — наведите мышь для полного.
  3. Если портал запрещает встроенные вкладки (защита сайта) — он откроется отдельным окном браузера автоматически.
  4. Приложение завершается само, когда главное окно закрыто.

Безопасность

🛡 Приложение локальное, не запрашивает и не хранит логины/пароли/ЭЦП. Вход — только на официальных доменах *.gov.by и официальных сервисах. Проверяйте адрес и сертификат страницы перед вводом данных.

О программе

Одно окно вместо десятков ярлыков — по мотивам BELPORTAL (belportal.by). Однофайловый exe, установка не требуется.
