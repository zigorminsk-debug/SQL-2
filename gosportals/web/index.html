Диагностика рабочего места

Проверка «настроек для входа» на госпорталы. Запускается автоматически при старте приложения; здесь можно повторить. Всё выполняется локально.

Что нужно для входа по ЭЦП

Юрлица и ИП работают на госпорталах с электронной цифровой подписью. Минимальный набор:

1. Криптопровайдер AVEST CSP

Национальное СКЗИ: без него не работают МНС, ФСЗН, Минфин, Белгосстрах, Белстат по ЭЦП. Есть бесплатный ознакомительный период.

avest.by → скачать/обновить

2. Сертификат ключа ЭЦП

Выдаётся удостоверяющим центром (РУЦ ОСТ, НУЦ, ГосСУОК — для бюджетников). Носитель — токен/флешка AVEST.

nca.by — Нац. удостоверяющий центр

3. Корневые сертификаты НУЦ / ГосСУОК

Ставятся в «Доверенные корневые» Windows, иначе порталы пишут «сертификат не доверенный». Следите за сроками — приложение подскажет об истечении.

nca.by · gosuok.gov.by

4. AvTuneProxy (вход «без ЭЦП»)

Нужен только для Корпоративного портала ФСЗН при входе по логину МСИ вместо ЭЦП.

avtunproxy.by → скачать для Windows

5. Браузер с режимом IE

МНС (физическая ЭЦП) и «Электронный респондент» Белстата работают в IE 11 или Edge в режиме IE. МЭЦП и логин/пароль — в любых.

6. Токен с драйвером

Аппаратный носитель виден в «Диспетчере сертификатов» (AvCertMgr) после установки AVEST CSP.

документация Avest →

Включение режима IE в Microsoft Edge

  1. Откройте Edge → «…» → Параметры → Браузер по умолчанию.
  2. «Разрешить сайтам перезагрузку в режиме Internet Explorer» → Разрешить, перезапустите Edge.
  3. «Страницы в режиме Internet Explorer» → Добавить страницу и введите адрес портала.
  4. Откройте портал из панели — страница загрузится в режиме IE.

Как работать

  1. При запуске приложение само проверяет сертификаты и зависимые программы — результат в полосе сверху. Красное — жмите ссылку «исправить».
  2. Клик по плитке — портал открывается прямо в этом окне. Возврат к плиткам: Alt+← (или кнопка «Назад»).
  3. Зелёная точка — портал отвечает. Серые — проверка, красная — недоступен (часто регламентные работы).
  4. ★ в углу плитки — в избранное. ⓘ — памятка «что нужно для входа».
  5. Вкладка «Настройки входа» — диагностика и инструкции по ЭЦП/МСИ/ЕСА.

Безопасность

🛡 Приложение локальное, не запрашивает и не хранит логины/пароли/ЭЦП. Вход выполняется только на официальных доменах *.gov.by и официальных сервисах — перед вводом данных проверяйте адрес и сертификат страницы.

О программе

Одно окно вместо десятков ярлыков — по мотивам BELPORTAL (belportal.by). Однофайловый exe, установка не требуется.
