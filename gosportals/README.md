# ГосПорталы РБ (GosPortals)

Настольное приложение на Go: **все государственные порталы Республики Беларусь
и необходимые настройки для входа — в одном окне**. Идейный аналог
[belportal.by](https://belportal.by): одно приложение вместо десятков ярлыков.

Три режима в одном exe:

| Режим | Флаг | Вид |
|---|---|---|
| **Отдельное окно браузера** (по умолчанию везде) | — | приложение открывает стартовую страницу в отдельном окне вашего браузера; все порталы открываются **вкладками в этом же окне**; консоль скрывается, программа завершается при закрытии окна |
| **Окно приложения app-режим** | `-app` | окно Edge/Chrome без элементов интерфейса браузера; порталы — во встроенных вкладках окна |
| **Нативный Win32-GUI** | `-native` | окно с таблицей, меню и треем (библиотека [lxn/walk](https://github.com/lxn/walk), без CGO) |

**При запуске во всех режимах автоматически проверяются:** наличие и версии AVEST CSP
и AvTuneProxy, корневые сертификаты НУЦ/ГосСУОК **со сроками действия**
(предупреждение за 60 дней до истечения — «пора обновить»), браузер и Edge.
Итог — в полосе сверху главного экрана, с кнопками «исправить».

## Возможности окна приложения

- 🧮 **Плитки-карточки порталов** (как в BELPORTAL): иконка категории, название, бейджи входа, статус доступности, заметка «что нужно для входа» по ⓘ, ★ избранное.
- 🪟 **Одно окно браузера**: стартовая страница и все порталы — вкладки одного окна. Приложение завершается при закрытии окна; консоль скрывается после запуска. (Опция `-app` — хромless-окно со встроенными вкладками.)
- 🧩 **База порталов сверена с [belportal.by](https://belportal.by)** (34 портала: МНС, ЭСЧФ vat.gov.by, ФСЗН, Белстат, Минфин, Белгосстрах, ЕГР, СККО, Второператор, маркировка, валютные договоры НБРБ, Е-ПАСЛУГА и др. + ЭДО и коммерческие сервисы).
- 📦 **Ссылки на ПО соответствуют belportal/offициальным ресурсам**: AVEST CSP (avest.by/crypto/csp.htm), NTClientSoftware и G-SecTLS Client (nces.by), АРМ Плательщик (nalog.gov.by), «Ввод ДПУ» ФСЗН (ssf.gov.by), NCM Crypto Plugin (goszakupki.by), AvTuneProxy (avtunproxy.by).
- 🛡 Стартовая проверка сертификатов и зависимых программ (см. выше) с повторной кнопкой ↻.

## Возможности нативного GUI (`-native`)

- 🗂 Таблица из 20 госпорталов: МНС, ФСЗН, Белстат, Минфин, Белгосстрах, ГТК,
  portal.gov.by, ЕСА, МСИ (ЕРИП), «Обращения.бай», закупки, pravo.by и др.
- 🔍 Поиск и фильтр по категориям, ★ избранное (сохраняется в `%APPDATA%\GosPortalyRB`).
- 🟢 Мониторинг доступности порталов (статус и время отклика, автообновление каждые 2 мин).
- 🩺 **Проверка системы**: AVEST CSP, AvTuneProxy, корневые сертификаты НУЦ/ГосСУОК
  (certutil), браузер по умолчанию, Edge для режима IE — кнопками открываются сайты исправления.
- ⚙ **Настройки для входа**: справочник по ЭЦП/МСИ/ЕСА, включение режима IE в Edge — внутри приложения.
- 📌 Значок в трее: сворачивание окна крестиком → трей; меню правым кликом, показ/скрытие левым.
- 🛡 Безопасность: **не запрашивает и не хранит логины/пароли**; кнопки открывают
  только официальные сайты (белый список вшит).

## Запуск (Windows)

`GosPortalyRB.exe` — двойной клик. Установка не требуется, права администратора не нужны.
Свежая сборка появляется автоматически в **GitHub Actions** после каждого коммита
(вкладка Actions → артефакт) и в **Releases** при тегах `v*`.

Флаги:

```
GosPortalyRB.exe                   # отдельное окно браузера; вкладки — в нём (по умолчанию)
GosPortalyRB.exe -app              # хромлесс-окно (app-режим Edge/Chrome), встроенные вкладки
GosPortalyRB.exe -native           # нативный Win32-GUI (таблица, меню, трей)
GosPortalyRB.exe -port 9000        # явно заданный порт
```

> Предупреждение SmartScreen («издатель неизвестен») — нормально для самосборного
> exe без платной подписи кода: «Подробнее» → «Выполнить в любом случае».

## Сборка из исходников

Go ≥ 1.22. Зависимости завендорены (`vendor/`), `vendor/modules.txt` — сети для сборки не нужно.
Ресурсы (манифест Common Controls 6 + иконка) уже сгенерированы и лежат в
`rsrc_windows_amd64.syso`, поэтому достаточно одной команды:

```bash
cd gosportals
# Windows GUI + веб-панель
CGO_ENABLED=0 GOOS=windows GOARCH=amd64 go build -trimpath -ldflags="-s -w" -o release/GosPortalyRB.exe .
# Linux/macOS (режим веб-панели)
CGO_ENABLED=0 go build -trimpath -ldflags="-s -w" -o release/gosportals .
```

Перегенерировать иконку и ресурсы (необязательно):

```bash
go run ./tools/mkicon app.ico && go install github.com/akavel/rsrc@latest
rsrc -arch=amd64 -manifest app.manifest -ico app.ico -o rsrc_windows_amd64.syso
```

> Модули в `go.mod` ссылаются на GitHub-зеркала через `replace`
> (`golang.org/x/sys`, `gopkg.in/Knetic/govaluate.v3`) — это осознанно:
> плюс закоммиченный `vendor/`, сборка полностью независима от прокси.

## Структура

| Файл | Назначение |
|---|---|
| `main.go` | диспетчер режимов, веб-сервер, API, проверка доступности порталов |
| `gui_windows.go` | нативный GUI на walk: окно, таблица, трей, диалоги |
| `gui_stub.go` | заглушка GUI для Linux/macOS (там работает веб-панель) |
| `checks_windows.go` / `checks_other.go` | диагностика окружения (AVEST, сертификаты, браузер) |
| `portals.json` | каталог порталов (правьте — и пересоберите / закоммитьте, CI соберёт exe) |
| `web/index.html` | интерфейс веб-панели (встраивается в бинарь) |
| `tools/mkicon` | генератор `app.ico` |
| `app.manifest`, `app.ico`, `rsrc_windows_amd64.syso` | ресурсы Windows (манифест UAC/DPI + иконка) |
| `vendor/` | зависимости (walk, win, govaluate, x/sys) |
| `release/` | готовые бинарники (в git не входят) |

## Дисклеймер

Программа — неофициальный агрегатор ссылок: все права на порталы принадлежат их
операторам (МНС, ФСЗН, Белстат и др.). Адреса и способы входа ведомства могут
менять — актуальные требования уточняйте на сайтах ведомств. Криптосредства
(AVEST CSP и др.) распространяются их правообладателями.
