# ГосПорталы РБ (GosPortals)

Настольное приложение на Go: **все государственные порталы Республики Беларусь
и необходимые настройки для входа — в одном окне**. Идейный аналог
[belportal.by](https://belportal.by): одно приложение вместо десятков ярлыков.

Ориентировано на бухгалтеров, ИП и граждан: порталы отчётности (МНС, ФСЗН,
Белстат, Минфин, Белгосстрах), госуслуги, таможня, закупки, справочные ресурсы.

## Возможности

- 🗂 **Каталог порталов** (20 шт. в 6 категориях): название, назначение, бейджи
  способов входа (ЭЦП, МЭЦП, МСИ, логин/пароль, ЕСА), памятка «что нужно для входа».
- 🟢 **Мониторинг доступности** порталов (зелёная/красная точка + время отклика).
- ⚙ **Диагностика рабочего места** (Windows): наличие криптопровайдера
  **AVEST CSP**, **AvTuneProxy** (вход в ФСЗН «без ЭЦП»), корневых сертификатов
  **НУЦ/ГосСУОК**, браузера по умолчанию, Microsoft Edge (режим IE).
- 📋 **Инструкции по настройкам для входа**: установка AVEST, сертификатов,
  включение режима IE в Edge, регистрация в **МСИ** и **ЕСА**.
- ★ Избранное, поиск, фильтры по категориям.
- 🛡 **Безопасность**: приложение локальное, **не запрашивает и не хранит
  логины/пароли**. Кнопка «Войти» просто открывает официальный сайт портала;
  бэкенд открывает только URL из вшитого белого списка.

## Запуск готового .exe (Windows)

Скачайте `release/GosPortalyRB.exe` → двойной клик. Установка не требуется,
прав администратора не нужно. Откроется консольное окно и браузер с панелью
(адрес вида `http://127.0.0.1:xxxxx`). **Консоль не закрывайте**, пока работаете,
выход — `Ctrl+C`.

Флаги (необязательно):

```
GosPortalyRB.exe -port 9000      # фиксированный порт
GosPortalyRB.exe -no-open        # не открывать браузер автоматически
GosPortalyRB.exe -addr 0.0.0.0   # раздать панель в локальной сети (осторожно)
```

> Windows может показать предупреждение SmartScreen («издатель неизвестен») —
> это нормально для самосборного exe без платной подписи кода:
> «Подробнее» → «Выполнить в любом случае». Исходники открыты, см. ниже сборку.

## Сборка из исходников

Требуется Go ≥ 1.22, внешних зависимостей нет (только стандартная библиотека).

```bash
cd gosportals
# исполняемый файл для текущей ОС
go build -trimpath -ldflags="-s -w" -o release/gosportals .
# кросс-сборка Windows x64 (из Linux/macOS)
CGO_ENABLED=0 GOOS=windows GOARCH=amd64 go build -trimpath -ldflags="-s -w" -o release/GosPortalyRB.exe .
```

## Структура

| Файл | Назначение |
|---|---|
| `main.go` | HTTP-сервер, API, автозапуск браузера, проверка доступности порталов |
| `portals.json` | каталог порталов (правьте — и пересоберите) |
| `web/index.html` | интерфейс (встраивается в бинарь через `embed`) |
| `checks_windows.go` | диагностика Windows: реестр (AVEST/AvTune/браузер), certutil (сертификаты) |
| `checks_other.go` | справочная диагностика для Linux/macOS |
| `release/` | готовые сборки (в git не попадают, см. `.gitignore`) |

### API (локальное)

`GET /` — панель · `GET /api/portals` — каталог · `GET /api/status` — доступность
· `GET /api/checks` — диагностика · `POST /api/open {id|tool}` — открыть
официальную ссылку в браузере · `GET /api/meta` — версия.

## Дисклеймер

Программа — неофициальный агрегатор ссылок: все права на порталы принадлежат их
операторам (МНС, ФСЗН, Белстат и др.). Адреса и способы входа ведомства могут
менять — актуальные требования уточняйте на сайтах ведомств и в службах их
поддержки. Криптосредства (AVEST CSP и др.) распространяются их правообладателями.
